CANCIONEIRO

Política de privacidade

O Cancioneiro é uma aplicação privada, sem fins lucrativos, para uso de um pequeno grupo de pessoas autorizadas. Esta página explica que dados são usados e para quê.

Entrada com o Google

Para entrar, usa a sua conta Google. A aplicação recebe apenas o seu nome e o seu endereço de email. São usados só para verificar se a conta está autorizada a ver os cânticos e para identificar a sessão. Não acedemos a mais nenhuma informação da sua conta Google.

Pedidos de acesso

Se uma conta não autorizada tentar entrar, o nome e o email dessa conta são enviados por email ao administrador, para que possa autorizar ou bloquear o acesso.

Cânticos preferidos

Os cânticos que marca como preferidos ficam guardados associados à sua conta, para os ver em qualquer dispositivo. Só a própria pessoa os pode ver.

Identificar um cântico pelo som

Quando usa o botão do microfone, alguns segundos de áudio são enviados para um serviço de transcrição (Groq) apenas para converter o som em texto e encontrar o cântico. A aplicação não guarda as gravações.

Onde ficam os dados

  • Base de dados e contas: Supabase.
  • Transcrição de áudio: Groq.
  • Envio de emails ao administrador: Resend.
  • Site: GitHub Pages.

Os dados não são vendidos nem partilhados com mais ninguém, nem usados para publicidade.

Apagar os seus dados

Para retirar o acesso ou apagar os seus dados (conta e preferidos), envie um email para tiago.mota@gmail.com.
